这是 [FoloToy AI Passport](https://ai-passport.folotoy.cn/) 上跑的 **Claude Pocket**
应用——一块开放、可穿戴的 ESP32-C3 小设备。按住按键说话,回答来自小幽,屏幕上的
一只小幽灵;她也能把活儿交给别的 agent,需要你点头的操作会先问你。设备通过加密
的低功耗蓝牙连着手机伴侣 App(没装 App 时,也可以在开发者模式下直连 Claude 桌面端)。
