# AI Character Reference Collection

Collected on 2026-10-12 for app and firmware character selection: whale maid, Claude, Codex and related AI personifications. The intended use is work-state and emotional expression. This is a link collection; no third-party artwork has been integrated and the final style is undecided.

## Source and reuse boundaries

The Moegirl source returned only a JavaScript notice; its complete article was not read. Gallery entries and several original Bilibili publications were cross-checked. Image URLs can change; publication links remain the provenance entry points.

The gallery labels some DeepSeek images CC BY-NC-SA 4.0; this is not a license for every character. YunYueSama distinguishes new contributions from third-party references in [ASSET_LICENSE](https://github.com/YunYueSama/codex-deepseek-pet/blob/main/ASSET_LICENSE.md). Code licenses do not establish artwork rights. Other assets require file-specific review before integration.

## Proposed next step

Not implemented: establish a consistent chibi whale-maid design, then show thinking, execution, reading, approval, input, completion, failure, retry, fatigue and rest. Keep Claude and Codex identities visible. Start dynamic emotion with constrained expression/action descriptions driving existing assets; generate new art asynchronously with review and caching. Real events determine work state. Firmware needs compact assets; the app can use richer artwork. Resolution, frame count and RAM budgets need measurement.
