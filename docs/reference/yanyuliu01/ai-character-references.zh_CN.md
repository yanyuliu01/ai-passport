## 下一步设计建议

以下是项目建议，尚未实施：以女仆鲸鱼娘为主形象，先统一 Q 版比例，再做思考、执行、查阅、等待确认、等待输入、完成、出错、重试、疲惫和休息等表现。Claude 与 Codex 保留各自角色特征和名称。情绪动态生成可先生成受约束的表情/动作描述，驱动已有资源；新图片与动画异步生成、审核与缓存。实际工作状态由真实事件决定。固件使用精简资源，app 可保留高清版，最终分辨率、帧数与 RAM 预算要实测。
