# 独立加密中继

这是用于公网可达主机的部署模板，需要 Docker Compose、指向该主机的域名和可入站的
TCP 80／443，不依赖 Tailscale。二维码负责设备配对，不会自动创建互联网路由。
已有可达主机时不必另买服务器。目前这台 Mac 没有已验证的公网直连路径；本模板尚未
在外部主机上部署或验收。

在 `companion/desktop/` 执行 `npm run build`，将 `dist-main/relay/server.js` 复制到
本目录；把本目录的副本部署到已授权主机。执行 `sh setup.sh relay.example.com`，
检查 `.env` 后执行 `docker compose up -d --build`。脚本保留已有 `.env`，不打印访问密钥，
请妥善保管。中继容器不发布宿主机端口，由 Caddy 提供 HTTPS／WSS 和自动证书，未配置请求／
内容访问日志。中继仅转发有身份校验、大小限制的密文，不保存聊天记录，也不是离线信箱；
只有端点软件负责解密。

在桌面高级连接设置一次性填入 WSS 地址和访问密钥，再生成两分钟二维码。Android 0.29.0 起，
进入「连接与设置 → 扫码连接电脑」，核对设备指纹并在电脑批准。一个 App 保留最多八台电脑
连接，每条连接单独固定设备公钥。同空间记录沿用 Runtime 的规范身份；扫描不同空间不会
擅自合并各自历史。

`docker compose down` 停止服务；保留 `.env` 和证书卷以便恢复。重启中继不会删除端点的
历史、配对和待发队列。需要撤销中继访问时更换访问密钥并重新分发；按设备撤销的界面尚未
实现。本轮没有实际部署任何服务。
