# 小幽中枢（Pocket Hub）

小幽中枢是一个安卓 App，位于手机上的各个 AI 助手和 Claude Pocket 设备之间。它读取
已登记 App 的通知（默认是 Claude 和 Codex），把最近的几条整理成一个小的消息流，
通过低功耗蓝牙发给设备。设备固件不用改：App 说的是和 Claude 桌面端相同的
Hardware Buddy 线协议，所以小幽显示手机消息的方式和显示桌面端状态一样。

中枢是一个独立的参与者，不是 Claude 的功能。它不认识任何具体的助手；一个“来源”
只是一个安卓包名加一个显示名称，可以在 App 里继续添加。

## 哪些内容会到设备上

| 手机上 | 设备上 |
| --- | --- |
| 已登记来源的一条通知 | 首页说明行、最近动态里的一条，以及“最新回复”页里的全文 |
| 还没被划掉的通知 | “等待”数量；小幽提示有事找你 |
| 同时带有“允许类”和“拒绝类”按钮的通知 | 小幽发问；`确认键` 触发允许按钮，`下键` 触发拒绝按钮 |
| 没有新消息 | 每 10 秒一次保活，让设备保持连接 |

能转发的只有通知里已有的内容。某个助手是否会为云端会话发通知、通知是否带操作
按钮，取决于那个助手的 App，目前没有验证过。

## 安装与设置

每次推送改动到 `companion/`，GitHub Actions 都会构建一个调试版 APK，并挂到名为
*Pocket Hub debug build N* 的预发布版本上。在手机上下载 `pocket-hub-debug.apk`，
并允许浏览器安装应用。

在 App 里依次：

1. 授权蓝牙。
2. 在系统设置里给本应用开启通知使用权。
3. 连接。设备屏幕显示六位配对码时，在手机上输入。

设备同一时间只接受一个蓝牙连接。连手机之前，先让它和 Claude 桌面端断开（或者
离开那台电脑）。

## 隐私

App 没有网络权限。已登记来源的通知文字只保存在内存里，只通过加密的蓝牙连接发给
已配对的设备，不写入存储。其他 App 的通知一律忽略。

## 结构

| 路径 | 作用 |
| --- | --- |
| `android/app/src/main/java/.../BuddyProtocol.java` | 线协议；纯 Java，有单元测试 |
| `.../Sources.java` | 来源登记表（包名、名称、是否启用） |
| `.../HubStore.java` | 内存里的消息流、待回答的提问、日志 |
| `.../NotifyListener.java` | 通知监听服务 |
| `.../BleLink.java`、`.../LinkService.java` | 蓝牙主机端，以及让它常驻的前台服务 |
| `.../MainActivity.java` | 设置、来源列表、测试按钮、日志 |

## 状态

协议层有单元测试，它的输出能被固件的解析器接受。App 能对照 Android 14 的接口编译
通过。它还没有在手机上运行过：蓝牙配对、各家定制安卓系统上的后台表现、真实的
助手通知，都没有验证。
